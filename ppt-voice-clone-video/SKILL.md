# PPT 语音克隆与字幕

把 PPT 图片、逐页讲稿和参考音频整理为可直接导入剪映的配音与字幕。英文场景默认采用本机 Chatterbox Turbo；用户已有模型、服务或音色选择时沿用其选择。

## 接入与复用

- 确认图片与讲稿逐页对应、参考音频位置、输出目录，以及用户希望试听还是已批准全量制作。
- 先检查已部署服务、模型和交付目录，避免重复下载权重或启动第二份 GPU 模型。
- 新部署、迁移或安装失败时，读 [references/chatterbox-turbo-deployment.md](references/chatterbox-turbo-deployment.md)：先验证 GPU，再处理依赖、中文路径安装、权重下载与完整短段验收。可运行 `scripts/deployment_probe.py` 检查环境，不必加载第二份大模型。
- 技术执行、故障定位和剪映交付见 [references/workflow.md](references/workflow.md)。
- 复用当前 G-NAOE 项目时读 [references/gnaoe-case.md](references/gnaoe-case.md)，其中包含已有路径、批准记录和脚本限制。新项目使用自己的清单、配置和输出目录。

## 执行流程

1. **准备参考声音。** 选择约 10–20 秒的单人英文片段，检查背景声、分离残留、混响和首尾静音。保存实际切片及位置。自动选段只是候选，需要检查。
2. **提供短试音。** 默认原速 `speed=1.0`，将比较样本匹配到相同响度再评价清晰度。用户要求先听后批量时，等待对具体样本的批准；已有批准在同一任务中持续有效，不重复确认。
3. **按页分段生成。** 保存原稿展示文本和实际朗读文本。数字、小数、缩写可在朗读版本中展开，字幕保留原稿。按自然句子或短意群分段，控制每次生成长度，记录真实片段时长及页内位置。
4. **按真实语音对齐。** 用已知原稿进行声学强制对齐，并用识别结果辅助检查漏词、重复和数字。强制对齐的高分不等于朗读内容正确。修正异常片段后重算该页及后续全局时间。
5. **切短句、保持单行。** 默认每条 SRT 的文字只有一行，按语义拆成多个短字幕块；编号、时间码及空行仍保留。约 2–6 秒、6–12 个英文词可作起点，以实际语速和画面宽度调整。用户要求双行时再使用双行。
6. **交付两套时间轴。** 逐页 SRT 从该页零秒计时；全局 SRT 对应合并音频。页间停顿同时计入合并音频和图片时长表。另生成每页一个完整区间的换页提示 SRT，帮助用户在剪映中吸附图片边缘。

## 声音与时间的约束

- 以用户批准的具体音频、参考片段、速度和响度为基准，记录这些设置并延续到批量结果。
- 默认原速合成与固定增益匹配。后期时间拉伸可能产生相位或金属感；发现问题先作同一波形、相同响度的对照，避免把不同次随机合成当作受控比较。
- 不用字数平均分配替代声学对齐；合成片段的粗时间也不是逐词时间。
- 不改原始图片、DOCX 和参考录音，不因发音处理改掉字幕中的数值、单位或科学结论。
- 音频、字幕和图片节点使用同一页间停顿约定。按视频帧率转换累计节点，避免分别舍入每页时长后相加。
- 核验文字覆盖、数字、缩写、时间单调性、字幕不重叠、不越页及音频峰值。只重生成确有问题的片段。

## 可执行字幕工具

`scripts/subtitle_tools.py` 只需 Python 标准库：

```powershell
python -X utf8 scripts/subtitle_tools.py single-line --input original.srt --output single_line.srt
python -X utf8 scripts/subtitle_tools.py page-guides --timings slide_timings.json --output slide_guides.srt
python -X utf8 scripts/subtitle_tools.py validate --input single_line.srt --max-lines 1 --audio-seconds 611.1
```

执行时使用实际绝对路径；`611.1` 只是本次案例时长。页表可用 JSON 数组或 CSV，字段见技术流程。脚本保留文字和时间，拒绝覆盖输入；输出存在且确实要更新时用 `--force`。

## 剪映交付与范围

用户自己操作时给出最短步骤：合并配音从零秒开始 → 导入换页提示 SRT → 图片按对应块边缘吸附 → 删除辅助文字块 → 导入正式单行英文 SRT。提示 SRT 是普通文本轨道，不是原生标记或已装配的剪映草稿。未在当前版本验证前，不声称支持 CSV 标记导入或精确时长输入框。

默认交付合并 MP3/WAV、单行全局 SRT、逐页音频与 SRT、图片时长 CSV/JSON、换页提示 SRT及处理记录。用户只问操作方法时优先解释手动用法；操作剪映、拼接视频或修改草稿文件应符合当前任务授权，不能仅因本技能涵盖配音而扩大范围。
